# Demo video script

Check the project statement for the time limit, whether your face must be visible and where to upload. The plan below fits about 5–8 minutes; trim to your limit.

| Time | Show | Say |
|---|---|---|
| 0:00 – 0:30 | Yourself, then the home page | Name, roll number, project title, one sentence on what the app does |
| 0:30 – 1:30 | Code editor: folder structure, `models.py`, ER diagram | How the app is organised; the main tables and relationships |
| 1:30 – 3:30 | Admin: login → dashboard → create venue → create event → search → flag a user → summary | Each core admin feature, one after another, no talking over long waits |
| 3:30 – 5:30 | User: register → login → search → book → my bookings → cancel → summary | Each core user feature |
| 5:30 – 6:30 | Postman or curl: GET list, POST create, a 400 and a 403 | The API and how it is protected |
| 6:30 – 7:00 | Any additional features; close | What you would add next |

## Recording tips

- Load demo data first (`python seed_demo.py`) so lists and charts are not empty.
- Zoom the browser to 125% and close other tabs and notifications.
- Rehearse once with a timer; cut anything that is not a project feature.
- Speak while you click; don't narrate code line by line.
- Re-watch before uploading: is every core feature shown?
