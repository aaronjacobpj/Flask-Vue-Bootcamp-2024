# Bootcamp session plans

Two 10-day bootcamps for the IITM BS Modern Application Development projects. Each folder has a `README.md` with the day-wise plan, and one folder per day with `NOTES.md` (session plan) and the code as it should look at the end of that day.

| Folder | Course | App built | Stack |
|---|---|---|---|
| [`MAD-I-EventHub-Bootcamp`](MAD-I-EventHub-Bootcamp/README.md) | MAD I project (BSCS2003P) | EventHub – event booking | Flask, Jinja2, SQLite, Bootstrap, Flask-RESTful, Chart.js |
| [`MAD-II-Quiz-Master-Bootcamp`](MAD-II-Quiz-Master-Bootcamp/README.md) | MAD II project (BSCS2006P) | Quiz Master – exam preparation | Flask API, Vue 3, SQLite, Redis, Celery |

MAD I comes first: MAD II assumes Flask, SQLAlchemy and Jinja basics from MAD I and moves the UI into Vue.
